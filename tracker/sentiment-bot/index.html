Sentiment Trading with LLM

BIST 30 evreninde LLM-tabanlı sentiment + kantitatif sinyal araştırması. Şu anda sinyal kalitesi geliştirme aşamasında.

Bot şu anki haliyle, walk-forward backtest'te XU100 buy-and-hold endeksini nominal getiride geçemiyor. Bu yüzden public dashboard pasif tutuluyor — yatırımcı bazında dürüstlük önceliği.
Devam eden iş: Tarihsel haber + sentiment veri ingestion (şu an %99 NaN), feature seti revizyonu, model değişikliği (LightGBM → ensemble / transformer denemeleri), long-short hedge mekanizması.
Kod ve bug fix'ler açık: github/bist-sentiment-bot. Repository sürekli güncelleniyor; signal kalitesi XU100'ü dürüstçe geçecek seviyeye ulaştığında bu sayfa canlıya alınır.
Not: Önceki yayında gösterilen +60% CAGR / Sharpe +0.40 metrikleri, _build_positions() içindeki bir ffill bug'ı sonucu 3× leverage gibi hesaplanıyordu. Bug düzeltildi (commit 7374c17); gerçek metrikler XU100'ün gerisinde olduğu için bu sayfa "in development" durumuna alındı.
