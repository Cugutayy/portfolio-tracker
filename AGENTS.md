# AGENTS.md

## Design / frontend instruction

Before modifying Journey or other visual portfolio surfaces, read and follow `/SKILLS.md`.

The user's standing preference is high-fidelity, editorial, production-grade implementation.

Important:
- Do not replace requested code/site work with image generation.
- Do not use crude placeholder SVGs for complex maps/data.
- Use real tools/data/content where possible.
- If a visual reference has been explicitly approved as "birebir", treat it as a design spec.
- Use the user's real photo archive.
- Preserve runtime correctness, responsive behavior, accessibility and performance.
- Verify builds and browser behavior after changes.
- When a rejected section is removed, remove it from the rendered DOM and clean up dead experimental code.
